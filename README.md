# 拾器 · AI 资源社区

发现、分享与复用优质 AI 资源与实战方案。

新版只收录与 AI 实践有关的资源和教程，覆盖设计与图像（建筑、服装等行业）、视频与动画、音频与数字人、应用开发、Agent 与自动化。资源、教程、专题、作者页均由服务端生成主要 HTML，浏览器增强发布、收藏、讨论和管理操作。

## 本地预览

需要 Node.js 22+。在项目目录执行：

```powershell
npm ci
npm run dev:local
```

打开 <http://127.0.0.1:4173/>。此命令使用开发依赖中的 PostgreSQL 17，不需要另外安装数据库。数据保存在 `.tools/postgres-preview/data`，停止后重新运行同一命令可以继续使用；该目录不要作为缓存清理。数据库只监听本机，使用本地开发认证，不用于生产。

首次初始化只创建开发管理员，不放入演示资源、作品或虚构统计：

- 邮箱：`admin@example.com`
- 密码：`ShiqiDev12345`
- 发布：`/submit`；个人中心：`/profile`；管理：`/admin`。

管理员可先补充平台和任务标签，再发布资源、记录核验和创建专题。普通用户通过邮箱注册；未配置邮件服务的开发环境会显示开发验证码。开发管理员也可以直接投稿。资源库为空时展示真实空态。

需要完全临时的数据时可以运行 `npm run dev:memory`，其数据会随进程退出清空。不要同时让两个服务占用 4173 端口；其他端口需要同时设置 `PORT` 和 `APP_ORIGIN`。

已有 PostgreSQL 17 的环境：

```powershell
Copy-Item .env.example .env
# 修改 .env 中的数据库连接和账号配置
npm run db:setup
npm run dev
```

Docker 本地开发：`docker compose up --build`，数据库及上传目录使用独立卷。Compose 中的密码和邮件设置仅适用于开发。

为查看前端样式，可在本地预览运行时手动执行 npm run demo:seed。

导入 15 条资源（含 1 条待复核示例）、8 篇教程和 6 个专题，覆盖五个 AI 领域，包含演示封面、精选、核验、修订、讨论、收藏与复现反馈。标题统一以“【演示】”开头，正文和核验记录说明其为虚构示例，外链为占位入口。

## 内容与维护规则

- 资源形态：工具与应用、模型与 LoRA、Skills、工作流、MCP 与插件、AI 模板与知识包、AI 项目源码。
- 教程包含任务目标、正文、可选的依赖资源、过程、成果、费用和限制。原创教程不强制来源链接，转载和改编必须注明来源。
- 注册用户直接发布，初始状态为待验证。普通软件、通用素材或“仅由 AI 写过代码”的源码不构成独立收录理由。
- 作者自测、资料核对、编辑复测分别保存版本、环境、证据和时间。编辑精选必须满足相应核验方法、使用条件及链接检查要求。
- 正文、用途、依赖、版本和关键链接变化会生成新修订；旧核验与复现反馈保留在历史版本。封面、标签和排版不会刷新核验时间。
- 默认复核周期为工具 14 天，模型/Skills/工作流等 30 天，不依赖版本的方法类教程 90 天。编辑调整周期必须说明原因。
- 到期或被要求复核的内容退出默认列表、首页和搜索；即使维护任务关闭，也由查询时的规则生效。详情保留提示；确认失效返回 410 和处理说明，缺失内容返回 404。
- 收藏、评论、举报和反馈均使用完整的 `{type,id}` 内容引用。复现结果按内容版本统计；评分可选。浏览量、收藏量、评分均取真实记录。

外部视频、音频、代码仓库和文件以明确的外链按钮打开；本站不托管模型或运行用户工作流。实战教程可通过编辑器插入 B站视频，详情使用 B站官方播放器，默认不自动播放。已有文章图片及封面上传保留，图片上限默认 512 KiB。分享声音与形象资源时需要说明来源和使用范围。

## 维护任务

维护任务运行在项目服务端，服务启动后检查并每小时继续处理。到期扫描至少每天执行；外链通常每七天检查一次，同域名每轮最多一条请求链，每轮最多 40 条，以到期顺序继续处理积压。

DNS 结果与每次跳转均检查公网地址，并固定连接地址，使用请求超时、有限重定向和轻量 HEAD 检查。403、429、登录和超时只标记需要核对；重复 404/410 进入人工复核，不自动确认失效。检查记录、下次执行时间和运行状态均持久化。失效依赖会向关联教程发出复核提醒。

```powershell
npm run maintenance:run
```

也可以在管理后台“维护任务”手动触发。`MAINTENANCE_ENABLED=false` 关闭周期任务，手动触发仍可用；`WRITE_MAINTENANCE=true` 暂停 HTTP 写请求，用于发布与事故处置。提示出现在个人中心和后台，未增加邮件订阅系统。

## 结构

| 目录 / 文件 | 职责 |
| --- | --- |
| `server/app.mjs`、`server/auth-api.mjs` | HTTP 路由、鉴权、账号和图片上传 |
| `server/community-policy.mjs` | 内容类型、输入规则、可见性、核验与精选资格 |
| `server/community-service.mjs`、`community-api.mjs` | 查询、发布、修订、关联、反馈、专题和管理 |
| `server/pages.mjs` | 服务端页面、SEO 元信息与 sitemap |
| `server/maintenance.mjs`、`link-check.mjs`、`public-address.mjs` | 持久化维护任务与安全链接检测 |
| `client/`、`app.js` | 按页面加载的交互模块、草稿、编辑器和管理表单 |
| `shared/`、`rich-text.js` | 前后端共用分类、展示和安全富文本 |
| `migrations/`、`scripts/` | 数据结构升级、启动和运维命令 |
| `tests/` | 单元、接口、PostgreSQL 与浏览器验证 |

使用原生 ES Modules、Node HTTP 和 PostgreSQL；不引入前端框架、向量库或消息中间件。旧 HTML、旧前端大文件实现和自动 OG 抓取路径已退出运行代码。数据库保留必要历史字段及关系，不再双写旧投稿表。

公开路径：`/resources`、`/articles`、`/topics`、`/creators/:id`、`/updates`、`/search` 及对应详情。旧 `#/resource/:id`、`#/article/:id`、`#/learning` 等地址由浏览器转换。私有页面及待验证、待复核详情不进入索引。列表默认 20 条，最多 50 条，使用稳定分页排序；`/api/bootstrap` 仅提供会话、配置和首页有限数据。

## 迁移与上线

```powershell
npm run db:preview -- --report=.tools/migration-preview.json
npm run db:migrate -- --report=.tools/migration-result.json
```

预览不改变数据库，报告列出待应用迁移及旧内容清单。迁移按文件使用事务，重复运行不重复复制数据或重置已核验的新内容。旧内容统一退出公开范围，原 ID、作者、收藏及真实访问记录保留，旧精选不沿用。需要保留的 AI 内容可由管理员补齐字段、确认收录范围后重新核验。

生产启动不含示例内容。`SEED_ON_START=true` 只用于首次初始化指定管理员，初始化后恢复 `false`。生产部署必须配置真实域名、HTTPS、数据库、持久化上传目录、固定的密码 pepper 和邮件服务。具体发布、备份和回退步骤见 [上线运行手册](docs/上线运行手册.md)。

## 验证

```powershell
npm run check
npm test
npm run test:postgres
npm run test:e2e
```

- `check`：全部 JavaScript 模块语法检查。
- `test`：26 项，其中 25 项通过；数据库事务约束专项在内存库中跳过。
- `test:postgres`：隔离的真实 PostgreSQL 17 执行 18 项接口、修订、约束与旧库升级用例，全部通过，不读取生产数据库。
- `test:e2e`：5 项流程，涵盖 360、768、1440 像素下的发布、草稿恢复、失败重试、编辑、关联、收藏和讨论，以及编辑核验、精选、专题排序、问题处理、维护任务和后台删除。

Windows 浏览器测试默认使用已安装的 Edge；其他系统执行 `npx playwright install chromium` 后运行。测试样例仅由隔离测试服务加载。浏览器截图及失败追踪保存在 `.tools/`，不会进入生产镜像。
